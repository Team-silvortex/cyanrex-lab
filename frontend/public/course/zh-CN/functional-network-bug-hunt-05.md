## 保留的行为与权威边界

- 请求携带会话、要求 no-store、禁止重定向。变更等待（含响应体）限时 330 秒，列表读取 20 秒。
  只是活跃浏览器等待上限，不证明服务端完成、回滚或清理成功；浏览器挂起可能延后计时器。
- 派发后编辑不会取消该变更，只隐藏过期输出，随后核对用户挂载列表。导航/离开取消等待，旧回调
  不能影响新运行或发起补充读取。不自动重试，也不自动卸载。
- HTTP 200 编译失败、有效 HTTP 400 失败运行报告仍按普通报告展示。明确的 400/401/403/404/
  413/429 错误保留服务端说明；网络、异常响应、超时和 5xx 则提示操作可能已生效。清理失败不代表回滚。
- 快捷卸载须同时有当前结果 pin 和包含它的有效列表。旧/失败列表可见且有标注，清理按钮禁用；
  有效空列表与读取失败分开。显式 `pin_path: null` 批量操作仍按原确认说明作用于当前账户在执行时
  的全部挂载（包括新增项），界面列表不是服务端冻结快照。
- 用户归属、已选头文件、CSRF 与 Runner 权限仍由 Engine 决定，清理核验交给所选驱动。
  未增加客户端指定所有者或隐式本地回退。
