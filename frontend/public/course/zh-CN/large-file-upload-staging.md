## 准备和暂存一个分块

[`FileUploadStaging`](../../engine/src/services/file_upload_staging/mod.rs)显式接收受信任上传存储、
已打开的私有 `ChunkStaging` 和 **1 至 16** 的控制额度。两者固定工作区必须一致。
构造不安装 SQL、不创建目录或改权限。`prepare(upload_id, owner, account_id, index)` 在
REPEATABLE READ, READ ONLY 事务中捕获当次观察的准确预留快照，冻结完整元数据、原 Schema
固定信息和分块坐标。不做文件系统 IO 或当前根健康检查；绑定只用缓存根身份。
后续暂存检查使用新鲜 READ COMMITTED 读取。

| 步骤 | 状态与结果 | 边界 |
|---|---|---|
| 准备 | 返回 `Ready` 和准确所有者/账号代次元数据 | 仅受信任过滤，不是认证或上传回执 |
| `stage_chunk` 准入 | 首次 await 前转为 `Unknown` | 拒绝不同发行句柄及非 Ready；控制额度拒绝仍 Ready |
| 核对原预留 | 新鲜的短只读事务 | 此检查失败不派发文件工作，但尝试仍 Unknown |
| 暂存字节 | 独占上传绑定文件、准确摘要/长度、封存、同步和原 inode 读回 | 不持 SQL 事务进行文件工作；保留不确定输出 |
| 核对账本与原文件 | 原命名空间/表身份和完整元数据，再检查原只读描述符及当前文件项 | 暂存后失败返回 `Unconfirmed`，不给回执 |
| 确认 | 返回不透明本地回执，转为 `Confirmed` | 仅内存确认，不是持久进度或整文件发布 |

只有发行该尝试的适配器及其克隆可以执行。尝试/回执没有序列化、克隆或恢复构造器。
已消费的 Unknown/Confirmed 尝试不能再次执行，包括错误或取消后。
重新准备的独立尝试是另一项受信任调用，**不是**恢复原尝试，也不提供跨进程禁止重试保证。

## 身份与文件来源

固定私有 `u1` 文件名绑定上传 ID、准确 Principal/账号代次、完整 typed 清单、块序号、
配置的安装/命名空间/表身份，以及原打开文件根的 device/inode。显示名不能选路径。
不使用每次尝试的随机文件名绕过 `O_EXCL`；任何已有绑定目标都冲突。
旧 `v1` 暂存命名保持不变，不能提供绑定回执。

存储捕获不透明预留固定信息，不能把两次普通 `get` 匹配当成存储代次证明。
后续检查在任何选择前使用 **READ COMMITTED, READ ONLY**，真实表锁等待不能保留等待前的
账本快照；比较原命名空间/搜索路径/表 OID 及完整选中元数据。不持锁进行文件 IO。
这是观察检查，不是文件系统/数据库原子事务，也不抵抗可信数据库管理员、同 UID/root
在检查后的任意更改。
后续准备捕获另一份当次观察的预留快照；可信写者修改元数据可产生另一份绑定。
逻辑预留配额并不限制保留文件的物理磁盘占用。

本地回执私有持有原只读文件描述符及已验证元数据；最终核对原对象和可见私有文件项，
即使字节相同但换文件也拒绝。保留描述符防止原 inode 在账本检查期间释放后复用。
每份保留回执持有一个描述符直至丢弃，不是全局描述符额度；不暴露描述符、路径或构造器。
重新按路径观察匹配字节不能制造历史回执；0400 权限不隔离同 UID/root，也不是 WORM 存储。

## 容量与错误

克隆共享适配器快速拒绝的控制额度，只限制存活准备/暂存等待方，不限制取消后仍存活的
后台工作、已返回回执、全部句柄或进程内存。原暂存工作额度另外由真实排队/运行任务持有，
等待方取消也不提前释放；同一暂存句柄的旧式和绑定暂存/核验使用同一工作额度。
提供的 reader 可无限阻塞；没有任务强杀、带宽限速或物理磁盘预留/配额，暂存仍会写入实际文件。

控制额度拒绝仍为 Ready。准入后，写前账本失败返回 `Store(error)` 且为 Unknown；
暂存工作额度拒绝、目标冲突或根前置失败可返回已知错误，但仍为 Unknown。
创建后不确定结果及任何暂存后账本/原文件核对失败均为 `Unconfirmed`。
不自动重试、收编、释放预留、重置状态、删文件或回滚配额；丢弃回执也不删字节。
