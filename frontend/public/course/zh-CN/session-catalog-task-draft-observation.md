# 目录草稿目标的只读观察

状态：**C2-AA 内部准备层，已收录于源码版本 0.5.5**。决策日期：**2026-10-11**。
源码发布：**0.5.5**（**2026-10-11**）。本 Unix 操作读取仍保存在内存的
[C2-Z 目录尝试](session-catalog-task-draft-publication.md)所固定的准确未知目标，把当前可读数据
与冻结定义和计划创建值比较。不确认先前写入、不收编进度、不改变尝试状态，也不允许重试。

分日期的未发布跟进及验证记录保留原源码版本与执行范围；收录于 0.5.5 不代表重跑或扩大这些证据。

## 操作与当前权限

`attempt.observe_unconfirmed(&self, token)` 返回
`Result<SessionDraftPublicationObservation, SessionDraftPublicationError>`，复用不含正文的已有
报告，而不把目录尝试转换成手动尝试。只准入 `Unconfirmed`；Ready 与 Complete 返回
`NoUnconfirmedStep`。非法或不同 token 在访问数据库前返回 `SessionChanged`。来源、工作区、
分配目标及冻结完整定义不能重新提供或替换。

原规范 Session 指纹将调用绑定到仍存活的尝试，不代表当前授权。已有读取器在自己的事务中
独立检查当前账户、审计成员、命名空间身份及最终会话。退出、过期或成员暂停仍返回类型化读取
错误。重新登录不能接管旧尝试，不增加独立权限预检查或回退读取器。

每次按准确未知步骤选择一个已有 `read_session_artifact` 或 `get_session_catalog_content_task`。
不新增直接 SQL 或业务写入。原读取事务仍可能取锁并提交，不是新增 SQL `READ ONLY` 模式；
逐命令期限仍生效，不构成整条流程期限、观察配额或跨调用一致快照。

## 当前比较与类型化失败

报告只含 `step` 与 `result`，不返回草稿文本、payload、token 或定义正文。
`SessionDraftObservedOutcome` 区分以下当前观察：

| 结果 | 授权读取发现什么 | 不能证明 |
|---|---|---|
| `MatchesPlannedCreate` | 当前有效元数据和有序文本符合准确计划目标；Task 另须携带冻结的完整 `Some` 定义 | 原发布来源、提交已确认、持久确认或之后仍相符 |
| `DiffersFromPlannedCreate` | 当前有效数据与计划不同，例如使用另一注册定义，或后续合法换版/状态变更 | 允许修复、覆盖、收编、删除或重试 |
| `NotVisible` | 该次授权读取在其时点没有发现所属可见目标 | 全局不存在、已回滚、没有进行中的写者或可安全重试 |

Artifact 观察读取准确分配修订，比较完整计划元数据与原始字节；即使 Artifact head 后来推进，
该修订仍可能匹配。Task 观察读取当前目录 Task 快照和当前有序文本，比较预期 Draft/修订/
所有者/清单及冻结完整定义，不能只比较引用。有绑定和无绑定定义都保持目录 `Some` 身份，
均不执行评估。

读取失败仍是类型化错误。同一引用下定义元数据或绑定被改写，或真实目录读取器遇到手动
`None` 记录，会返回其类型化 `InvalidRecord`。字节损坏或命名空间不合法也保留读取器的
类型化错误，都不能变为 `DiffersFromPlannedCreate` 或 `NotVisible`。
另一合法注册定义可以产生 `DiffersFromPlannedCreate`；篡改同编号元数据不能模拟这种有效差异。

Task 存在时，原目录读取在同一事务中检查当前定义及当前引用字节，不另外重读尝试的整个历史
Artifact 前缀。Task 不可见时，已有提前返回检查来源和 Task 边界，不检查 Artifact 命名空间。
这不是整个工作区健康检查，也不证明原存储代次。相符数据也可能由另一写者在分配身份下创建。

## 状态与恢复限制

观察只不可变借用尝试。匹配、差异、不可见、读取错误或取消，都不追加确认、不标记 Task 完成、
不清除未知目标，也不允许 `advance`。各次观察时点独立，进行中的写者可能在 `NotVisible`
之后完成。元数据报告须保密，不是回执、幂等键或恢复权限。

目录尝试仍是绑定原 Session 的调用者内存状态，不提供检查点、日志、恢复、重试、清理或转换
旧手动 C2-P–W 类型。原 [C2-Q 观察](session-task-draft-observation.md)保留手动读取器和 `None`
比较；共用报告 DTO 不共享尝试状态或发布权限。不增加 HTTP 路由、签发、OpenAPI/SDK/浏览器
流程、提供器评估、Schema 迁移或部署连接。

## 验证边界

目录观察用例须单独检查准确状态/token 准入、完整定义与有序字节比较、有效差异与类型化损坏
的区别、当前 Session 拒绝、读取范围、进行中的写者、取消及尝试/资源状态不变。源码守卫和纯
检查不能替代临时数据库/文件执行。当前选择清单见[测试指南](testing-guide.md)，实际分日期
结果及限制见[项目状态](project-status.md)。

[功能张量](capability-maturity.md)只扩展 W16 的实现引用；旧手动观察证据保持原日期及范围，
目录源码不继承这些结果，不刷新评分、证据或拓扑。
