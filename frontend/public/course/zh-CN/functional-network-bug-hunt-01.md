## 已复现并修复

| 编号 | 断点 | 原有问题 | 本轮修复 |
|---|---|---|---|
| BH01-01 | D03 → F27/F29/F30 | 本地文件损坏时，4 个读取接口返回 200 空记录/零进度/空课堂；选中 SQL 后失败也可能读旧本地副本 | 读取方法返回 `Result`，路由返回通用 500；选中 SQL 的本次读取不降级，成功读取及存储错误均 no-store |

| BH01-03 | F28/F31 → D03 | 固定临时文件名会跟随已有符号链接并截断目标 | 随机同目录名称与排他创建，不触碰原有临时路径 |
| BH01-04 | F28/F31 → D03 | 最终 rename 失败后残留包含源码/评语的临时文件 | 作用域清理本次创建的临时文件，保留旧快照并可重试 |

首轮在旧实现上运行 7 条新增回归，全部失败：4 条 HTTP 读取、3 条持久化边界；已有学习联动回归通过。
修复后这 8 条全部通过。另补充两条关闭连接池的故障注入与一条合法空课堂回归，以及 API 错误契约测试。
关闭连接池测试在查询前关闭惰性连接池，不连接真实数据库；分别覆盖模式未就绪/已就绪和冷/热本地快照。

读取错误不能覆盖损坏文件、泄露存储内容或触发运行；修复测试文件后重新读取恢复原记录与评语版本。
401/403、教师筛选、学生归属、旧 JSON 数组、反馈并发冲突、取消后完成已交接提交等保障保留。
