Cyanrex 正转向与具体任务类型解耦的协作平台，eBPF 教学保留为首个领域，而不再定义所有工作的
形态。目前已形成持久化协作准备层和本地任务内容编辑器，**尚未形成服务端保存的通用任务闭环，
也没有替换现有教学运行链路**。本文描述全项目现状；逐轮实现、日期和验证细节保留在
[开发历史记录](development-history.md)，不再混入当前待办。

| 0.5.6 · 文件发布及私有元数据准备层 | 已确认日志／新鲜字节之后的独立可信发布；独立当前 Session 本人预留及上传／Published 元数据读取，保留原身份及最终策略／到期检查 | 无真正 Session 发布、发布／接收授权、物理封存、恢复或传输；可信发布器可能已有记录而仍 Unknown |
| 0.5.6 · 文件授权契约准备层 | 纯粹比较准确工作区、账号代次、文件版本、状态和有效期 | 无认证签发方、持久授权、新鲜策略／撤权查询、Session 连接或字节访问权限 |

产品版本、API 兼容基线和各存储 Schema 编号独立演进。源码版本为 0.5.8，公共 API 兼容基线仍为
0.3.0；当前 Task 存储要求在全新独立命名空间安装 Schema 2，拒绝 Schema 1 而不迁移。
正常启动路径和本次源码发布都不会升级数据库。
0.5.0 收录的内容存储独立要求 Schema 3；Schema 2 句柄及既有 Session 适配器拒绝该格式。两种格式都需要
各自显式安装的全新空命名空间。
准备层认证另要求来源 Schema 2 以支持 OTP 原子消费；安装及读取均拒绝已有来源 Schema 1，
包括空实例，不自动迁移。

## 任务内容不等于代码要求

Task 描述要完成的工作，可选 payload 可以是笔记、代码或配置；编辑文本不代表创建或执行 Run。
新 `/tasks/new` 页面持有草稿，`/editor` 进入同一容器，原 `/ebpf` 工作台仍独立保留。

本地草稿最多包含 32 个文本项，每项最多 256 KiB，整份 JSON 导入导出也有上限。文件名、语言和
内容由父任务持有；确认与修订检查阻止过期导入或回调覆盖新内容。草稿仅存在于页面内存，下载是
本地导出，不是服务端保存。操作与限制见[任务内容编辑](editor.md)。
0.5.5 收录的草稿独立于 14 种已安装配置接纳有界 ASCII 语言标记。未知标记在导入导出时原样保留，
使用不带语言工具的纯文本编辑；能力解析不是 payload 编辑，也不会自动改写语言。

JS/TS 提供浏览器本地语义辅助，JSON/HTML/CSS 使用配置的本地提供器；Rust、Python、C/C++ 等
基础配置仅有高亮/片段，没有外部语言服务器。尚未接入 rust-analyzer、Pyright、clangd、项目
文件系统或 LSP 传输。语言反馈不是执行或验收，共享浏览器工作线程也不是安全沙箱。

服务端使用另一套身份契约：准确的所属 Artifact 修订、当前 Session 授权和 Task 修订条件。
[Draft 换版](session-task-revisions.md)在任务/outbox 写入前后复核旧、新内容，旧内容及 Review
保持不变。发布 Artifact 仍是单独操作。文件名/语言、任务改名、导入语义和浏览器保存/冲突处理
尚需明确的公共契约，不能用本地 ID 代替。
0.5.0 收录的 [C2-K 清单](task-content-manifest.md)定义元数据与纯一致性检查。
[C2-L](task-content-store.md)另行增加可信存储与原子编辑，不改变已有 Schema 2 记录或 Session 命令。
[C2-M](session-task-content.md)现已内部组合当前 Session 和精确 Artifact 文本检查；
经过授权的浏览器保存流程仍未接通。
0.5.5 收录的显式目录模式为此文本组合加入精确冻结定义；标题、文件名和语言标签独立于定义元数据，
保留修订及字节校验。其独立工作区不能进入既有手工 HTTP 或草稿发布路径。
0.5.5 收录的独立 [C2-Z 发布器](session-catalog-task-draft-publication.md)使用该目录工作区而不转换为
手工尝试：固定完整准确定义，逐步发布 Artifact，最后通过既有 Session 命令创建目录 Task。
失败后保留已确认前缀；这不是整份草稿原子事务、检查点恢复或浏览器保存。
独立 [C2-AA 观察器](session-catalog-task-draft-observation.md)经既有当前 Session 命令读取该存活
尝试的一个未知目标，比较冻结完整定义与原始有序内容，不采纳回执，也不改变停止状态。
[C2-N](task-content-http.md)补充独立 HTTP 边界，但不挂载到现用应用、不签发凭据、不发布 Artifact，
也不连接浏览器。
0.5.5 收录的 [C2-X](text-artifact-http.md)路由另行发布一个有界文本 Artifact 并读取精确修订。
返回的 pin 可进入独立 C2-N 请求；两路由不互调、不合并，序列不是原子事务，也未接通浏览器保存。

0.5.3 收录的 [C2-O](task-draft-publication.md)补充纯导入与发布计划映射：拒绝空白标题而不补造标题，
经过校验的本地身份会丢弃。给定精确内容可绑定为清单，但字节相符不证明发布，也不授权后续命令。
该发布版服务端已接受合法扩展语言提示，浏览器当时仍限于已安装配置；0.5.5 收录的本地编辑器现独立于
能力配置保留这些合法标记。纯导入器自身不派发发布，C2-P 另提供内部组合，浏览器保存仍未接通。

0.5.3 收录的 [C2-P](session-task-draft-publication.md)另行组合当前 Session 发布与 C2-M Task 创建，
每次只执行一个写入。固定的调用者持有尝试保留确认进度，派发失败或取消后停在未知步骤。
它没有持久回执、自动恢复或浏览器/公共连接；每条命令仍独立复核当前权限。

0.5.3 收录的 [C2-Q](session-task-draft-observation.md)另以原 Session 观察固定未知目标。当前数据
匹配不确认先前写入，不可见不证明回滚；观察保持尝试停止，不提供重新登录或重启恢复。

0.5.3 收录的 [C2-R](session-task-draft-checkpoint.md)导出上限 64 KiB、没有正文或认证材料的元数据
检查点。解析只校验结构和一致性，不验证报告历史；不保存或读取，不复活 C2-P，也不调用 C2-Q，
持久结果仍须另行处理。

0.5.3 收录的 [C2-S](session-task-draft-inspection.md)另提供当前授权下的单检查点目标显式读取，
不要求原尝试仍存。元数据相符不证明原始字节或历史调用者；解析仍无 I/O，C2-Q 原 Session
要求不变。它不带来确认、日志、状态恢复或重试。

0.5.4 收录的 [C2-T](session-task-draft-intent.md)另以当前 Session 授权登记真实未开始尝试的规范
元数据。新 Session 仅在所有者及精确账号代次相同时可读记录。配置的日志安装 ID 与命名空间名称
不证明原资源代次或发布历史。C2-P `advance` 仍不要求日志；仅登记不是派发前持久化的执行流程，
也不授予恢复或重试权限。

0.5.4 收录的 [C2-U](session-task-draft-dispatch.md)将该初始尝试消耗为独立日志化包装器。每次推进先
确认 Unknown 预留，再重新授权，使准确步骤标记与一个 Artifact 或 Task 事务共同提交。只有确认
成功才推进内存进度，不确定结果使其停止。存活包装器可经多次成功步骤完成多内容项草稿，但丢弃
或进程退出后，读取意图/检查点不能重建包装器。

0.5.4 收录的 [C2-V](session-task-draft-journal-inspection.md)另报告已记录提交步骤数（包含末尾
Task 步骤）及可选 Unknown 目标。新 Session 必须匹配意图的精确所有者/账号绑定。读取复验
完整前缀及当前事务边界，不检查资源内容或发布历史；缺失不是回滚或重试证据。
其验证与下方历史 C2-T/U 记录独立。

0.5.4 收录的 [C2-W](session-task-draft-journal-observation.md)另选择已记录序号，读取精确
Artifact 修订或当前 Task 及引用内容，复验原完整日志与首次身份后才返回。记录的 Unknown/
Committed 与当前元数据是否相符分别表达，都不是回执或恢复许可。本片执行证据独立，
C2-V 仍不读取资源或文件。

## 转型期间保留的安全和兼容边界

- 原自部署教学保持教师权威，单人教师同时负责部署管理。准备层区分成员关系与显式实例 Grant；
  新空间所有者不会因此获得他人的私人内容或其他实例的部署权限。
- 会话资源命令从服务端解析所有者，并在确认提交前复核账号代次、经审计的活跃成员和当前 Session。
  直接接收 owner 的存储接口是可信内部基础设施，不是授权 API。
- 新持久存储拒绝不可用或不兼容的后端，不静默采用旧运行时的内存/文件降级。现用教学存储尚未
  切换或迁移。
- 超时、取消或提交回执丢失不能证明已经回滚。内容发布/引用换版失败不授权删除不可变文件，也不
  授权盲目重试命令。
- 特权本地 Engine 面向可信自部署，不面向公网多租户。共享内核的配额不等于学生隔离；注册的编译
  Agent 不是 AI 参与者或远程内核沙箱。内存作业、挂载和模块状态尚无多副本协调。
- Task 状态、运行成功和 Review 判断相互独立。私人记录或固定元数据不能代替通用任务验收、共享
  审阅授权或策略执行。
