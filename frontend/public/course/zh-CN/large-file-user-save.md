## 独立目标策略

`FileSaveTarget::open_user_directory(parent, leaf)` 只接受当前有效 UID 所有的已有普通目录，
完整权限位准确为 **0700**、**0750** 或 **0755**；拒绝组／其他人可写、特殊位、其他模式、
软链接、缺失或非目录，不修复。旧 `FileSaveTarget::open` 仍只接受私有 0700，
`ChunkStaging` 和 Artifact／私有根政策不变，不静默 fallback 到普通目录。

两构造器共用既有受保护祖先、描述符相对 no-follow 遍历：绝对有界路径，祖先为 root／
本 UID 且组／其他人不可写，仅保留既有 root 所有 sticky 祖先例外；例外不适用于最终目标。
名字由宿主独立选择，不采用远端元数据；仍为 **1–255 UTF-8 字节**，拒绝控制／分隔符／
点名字。构造不建父目录、不改模式、不预留名字、不打开输出。

普通目标保有原目录 FD 及 **dev／inode、UID、GID、完整权限位**安全快照。每次后续核验
均比较原 FD 和新 no-follow 遍历结果与原快照；0755→0750 即使两者分别允许也拒绝。
恢复原策略及原 inode 可使存活目标重新健康，不采用另一同模式目录。

不冻结目录 mtime／ctime／长度／link 数：自身新文件创建会合法修改它们，同一父目录的
不同显式名字也可以并发复制。这里是当时观察到的身份／策略核验，不证明中途从未变化。

## 原对象校验与资源所有权

仍共用原拼装证明、暂存 worker gate 和独占保存核心。源核验后才以请求 **0600**、
`O_EXCL | O_NOFOLLOW` 创建；校验流复制、最终 **0400**、文件／父目录同步和原 inode
实际 SHA／EOF 读回不变。已有条目只冲突，不写入、改名、采用或删除。源块和私有 `f1`
保留，保存仍另占整文件副本。

`ChunkStaging::save_assembled_file` 与 `FileChunkClient::fetch_granted_and_save` 使用同一
不透明目标类型。同源根仍在 worker／整流程准入前以缓存身份拒绝，不新增 semaphore、
远端请求、重试或进度日志。真实排队／运行任务跨等待者丢弃保有目录 FD、原证明、worker
和可选父流程名额；取消不返回确认，但原任务仍可能完成，不新起编排。

坏名字返回 `InvalidInput`，不可用父目录返回 `Unavailable`。创建前检查发现父目录漂移
为 `Unavailable`，不创建目标；检查后的竞态仍可能为 `Unconfirmed`，最终核验发现漂移
也为 `Unconfirmed`，保留部分或完整输出。静态错误
不授予回滚、清理、覆盖、采用或自动重试权；旧错误枚举及 move-only `SavedFile` 元数据
getter 不变。

## 隐私与剩余边界

0750／0755 父目录**不是私有暂存**，依祖先权限，其他本地用户可能列举名字或观察目录／
文件元数据。输出 Unix 模式仍只允许所有者读取，但不隐藏文件名，也不隔离同 UID／root
变更、非标准 ACL、挂载或网络文件系统；模式核验不代表跨用户读取实测或永久物理封存。

该构造器是可信本地宿主选择，不是非可信请求 DTO、工作区 grant 或任意写特权 Engine
路径的许可。共享可写目录仍不支持。界面确认／文件选择、公开 Session 签发／HTTP／SDK、
正常应用挂载、进度／续传／重启、物理配额、点对点和部署验收保持独立。

可选[实时交付观察](large-file-delivery-progress.md)报告使用此目标的显式交付阶段与块ACK，
目录构造器／独立保存本身不增加观察者。全部暂存计数或通道关闭不是保存回执或任务终止证明。
