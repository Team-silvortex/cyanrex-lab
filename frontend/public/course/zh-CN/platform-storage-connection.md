源码 **0.6.3** 已收录显式回环／TLS 宿主、受限 Session 签发及私人 Task 创建／列举／重开／清单换版。
不接通浏览器／SDK 保存、新字节发布、局域网或存储迁移；早期实施阶段标签保留原范围与证据。

已于 **2026-10-15** 收录至源码 **0.6.1**，见[发布验证](../../reports/releases/0.6.1/README.md)。
下文保留原实施阶段及验证范围；源码收录不代表部署验收。

这是 **0.6.0** 之后的未发布跟进，属于
[平台宿主提案 3](https://github.com/Team-silvortex/cyanrex-lab/issues/3)。
它组合现有数据库连接器、五个存储标记观察及私有 Artifact 根观察；每次显式调用都比较这三类
原绑定，全部通过才交出一条新连接。这仍是未挂载的库，不是运行宿主或当前 Session 授权。

独立未发布的[声明式存储打开](platform-storage-open.md)现核完整可信声明，确认初始连接关闭后
才返回本保留绑定能力。

## 显式构造

`PlatformStorageConnector::new(config, database, original_markers, root_path, original_root)`
消耗可信 `PlatformDatabaseConnector` 和调用方选定的真实标记／根观察。构造不做文件系统或
数据库 I/O；完整配置不一致、数据库绑定不匹配标记内目录观察、根路径原始拼写不符，都返回
固定 `InvalidConfig`。即使只是在路径末尾追加 `/.`，也不是原路径。

数据库连接器可持有[原观察](platform-database-connection.md)或
[显式目录声明](platform-catalog-expectation.md)，两种都须匹配所给
[标记观察](platform-storage-markers.md)内的真实完整目录，而不只是名字或作用域。
不会把声明转换成观察值。

“原”指可信调用方独立选定的观察时点。构造器不发现、检查或收编首次运行基线，不从诊断导出
观察，也不证明观察之前的历史身份。[check-storage](platform-storage-check.md)仍丢弃全部观察，
不能用于填充此 API；调用方须独立取得并信任这些观察，不能凭它证明在可信观察之前没有同名替换。

原根观察继续私有持有原目录描述符。新连接器没有 Debug、Clone、序列化、密码／选项访问器、
公共根描述符或更新基线的 API。

## 连接顺序与失败处理

`connect().await` 先同步复验原 [Artifact 根](platform-artifact-root.md)；不安全或被替换的根在
拨号前拒绝。随后进入共享十秒预算的数据库阶段：一次新连接、原目录核验、原五标记的身份、
版本、所有者及作用域核验。标记检查失败会在同一预算内关闭未发布连接；取消或到期则丢弃
未发布状态。

数据库阶段之后，即使数据库工作失败，也再次复验原根。只有数据库及根检查同时成功，才交出
调用方自有的 `PgConnection`。数据库成功但根后检失败时，另有独立十秒关闭预算。任何失败均
返回固定 `Unavailable`，不带文件系统、SQL 或驱动原始细节，不采纳替换身份，也不重连。

两次文件系统检查都在数据库预算之外，**没有硬耗时上限**，包括 NFS／FUSE；最终根检查期间
私有持有已核验连接。因此不能称整个连接十秒完成。两笔数据库事务与根检查是独立快照，
不是跨资源原子锁，也不提供持续身份保护。

精确恢复原对象后，后续显式调用可以成功；不自动重试、回退、迁移、安装、修复权限或清理
应用数据，也不授权重放不确定业务命令。超时／取消不证明远端服务器已经结束回滚。

## 调用方责任与剩余组合

返回连接**不强制只读**；只有验证事务只读，调用方之后仍可改变连接状态。业务命令仍须保留
原事务内 Source、资源及新鲜 Session 授权守卫。标记通过不证明完整 schema 或业务健康，
根核验只读元数据，不检查正文。

原[本地端点及秘密规则](platform-database-connection.md)不变：物理身份在数据库认证后核验，
不在密码交付之前；须独立信任本地对端，并负责日志策略（包括服务端通知）。
不增加 SQLx 选项、环境默认值、连接池、监听、签发、CLI 模式或配置格式。

此 Unix 库不准备进程；可信宿主仍须在秘密、工作线程及连接之前另行应用
[Linux 进程门禁](platform-process-startup.md)。2026-10-16 未发布的
[已有会话适配](platform-session-connection.md)现无连接池地消费此连接器，在查询／退出事务内
复验原目录／标记。资源适配、正常平台启动、安全 Session 签发及浏览器保存仍须独立推进，
不构造或切换教学 Engine。

## 验证

```bash
bash scripts/test-platform-storage-connection.sh
```

使用显式一次性 `CYANREX_TEST_DATABASE_URL`，要求角色／数据库管理能力及运行角色密码认证，
允许仅对管理员使用本地 trust。脚本先核对准确用例名存在，再执行。测试覆盖观察／声明兼容、
混合绑定、首次连接前标记／根替换、漂移不修复和精确恢复；真实环回探针检查前检拒绝，
用 inotify 阳性对照把前检打开与已接收数据库对端失败后的根后检分开观察。独立确认 PostgreSQL
标记锁等待后，分别在数据库核验期间替换根及取消组合连接 future，随后显式健康调用成功。
最终断言前回收自有资源。
这些是本地回归，不是局域网／TLS 部署、公共授权或浏览器保存验收。
