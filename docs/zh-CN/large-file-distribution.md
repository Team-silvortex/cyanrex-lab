显式[单块客户端](large-file-chunk-client.md)现为可信固定 Origin 补上受控请求，不挂该路由或
签发 Session。证书／SAN 核验、无自动重试／跳转／代理／解码及请求准入跨真实保存工作保留，

另行[私有拼装](large-file-chunk-assembly.md)现从已有旧式 `v1` 块独占创建整文件 `f1`，

首个用户流程是：有权限的发布者上传文件，明确选择接收者，接收者按准确发布版本下载，
支持可验证的断点续传与完整性检查。教师管理实例部署，工作区发布者仍需显式发布权限；
两者都不能据此读取他人的私人 Artifact。

## 现有边界

当前 [Artifact 存储](../../engine/src/services/artifact_store/mod.rs)整块缓冲内容，上限为
1 MiB；[文本 HTTP 适配](text-artifact-http.md)另限解码文本 256 KiB，且仍未挂载。
它的 JSON 收集器和原事务期限不是大文件流式基础设施。旧限额、Schema 与私人所有者过滤不变。

原生发布工具已有固定缓冲增量哈希与经确认的 OS SSH 访问；[SSH 部署](classroom-connection.md)
只操作预先安装的包，不上传安装包。课堂发现和邀请不提供设备身份或文件分享权限；现有准备层
HTTP 路由也不能直接构成已认证的在线文件分发流程。

## 建议的组件职责

| 组件 | 职责 | 不提供的权限 |
|---|---|---|
| 文件传输契约 | 不可变文件身份、版本、长度、有序分块与整文件摘要 | 解析不认证发布者，也不验证真实字节 |
| 私有暂存与字节存储 | 有界流式 IO、独占临时文件、持久确认分块及不可变发布 | 不接受任意磁盘路径，不执行、解包或扩大私人读取 |
| 发布与接收授权 | 准确发布者/账号代次、工作区、版本及明确接收者 | 摘要、发现标签、教师角色均不等于下载权限 |
| 集中传输适配 | 认证上传、状态、完成及准确版本分块下载 | 不自动挂载、对公网开放、降级认证或迁移 |
| 客户端传输控制 | 取消、校验后进度、目标保存确认与显式续传 | 浏览器回调/检查点不等于服务端回执或磁盘保存完成 |
| 后续桌面互传 | 沿用文件/分块校验，单独认证节点 | 不信任自报地址，不自动配对，不共享 Runner/SSH 秘密 |

控制命令与文件字节使用不同预算。目标数据服务运行在无特权进程中，不持有内核能力或
Docker socket，客户端不持有数据库凭据。不能为了分发文件直接暴露特权教学 Engine。

## 首版协议建议

新增独立版本化传输契约，不把大文件伪装成文本 payload，也不提高旧 Artifact 限额。
不可变清单包含文件/版本身份、总字节长度、固定块大小、有序分块 SHA-256 和整文件 SHA-256。
规范显示文件名只是元数据，不是存储路径；同一清单之后可适配集中与桌面传输。

当前准备层已固定 **4 MiB 分块、每文件 64 GiB、最多 16,384 块**；网络适配仍待审阅。这些是协议上限，
不是可用磁盘容量承诺；可信部署可配置更低的逐账户和总预留配额。长度/偏移必须防溢出，
错误块数、重复字段、未知版本、缺摘要或非规范摘要均拒绝。空文件有零块，且须验证空内容摘要。

首个网络适配每次只传准确一块，不支持任意多区间响应。块序号、预期长度和摘要绑定一个
不可变清单。上传使用二进制字节，不用 Base64/JSON；下载固定为附件和二进制媒体类型。
文件名不能成为执行路径；浏览器和原生客户端各自需要经审阅的保存机制，才能声称磁盘已保存。

## 上传和发布流程

1. 当前权限确认后开始上传，预留有界磁盘配额，记录不可变意图、发布者账号代次和清单身份。
   请求不能选择存储根目录。
2. 固定缓冲将每块写入私有独占临时文件，核验实际字节、准确长度和摘要后才持久确认。
   既有块序号的不同内容拒绝，不覆盖。
3. 显式查询/续传重新授权并检查已存分块，才报告已验证进度；导入位图或本地成功回调不够。
   重启恢复须核对字节、原上传身份及存储代次。
4. 完成操作按序增量验证整文件长度和摘要；缺块、损坏、过期或撤权不能发布。
   只有持久发布确认后，该准确版本才能授予接收者并下载。

整场流式传输和哈希不能持有原十秒 Session 事务或工作区写锁。短命令分别授权/预留、核对
暂存结果和确认发布；IO 后最终持久核对须拒绝已变化的身份、权限或上传状态。
文件持久化与元数据提交不是一个跨文件系统/数据库事务。

结果不确定时保留证据，显式查询准确当前状态。重试语义必须绑定原上传与不可变分块，拒绝
冲突内容，不能收编其他文件。不声称恰好一次交付，也不自动删掉未知结果文件。取消只停止
新准入；清理须确认上传状态、无存活工作/读取者，并审阅准确目标。

## 分发授权

发布者明确批准接收者和不可变文件版本、长度与摘要。授权绑定一个权限域/工作区、接收
账户代次，以及到期/撤销状态。重建同名账号不能继承权限，列表本身也须保持私有。

每次分块下载复核当前认证、成员资格、接收授权、发布状态和时效。知道编号/摘要、拥有邀请、
或具有管理角色均不足以下载；旧版本授权不能跟随替换。撤销拒绝后续准入块，但无法收回
已经送达的字节；在途撤权窗口须有明确上限和说明。

短期设备凭据、配对和节点传输委托属于后续桌面阶段。不能使用全局 Agent 注册 token、URL
中的 Session、SSH 私钥或可重复课堂邀请替代下载权限。局域网仍要求 HTTPS 身份核验或
经确认的 SSH 隧道；发现不是认证。

## 资源和磁盘安全

实际磁盘/哈希工作与 HTTP 请求分别限额；工作派发后，即使调用者不再等待，也须持有名额
直至实际结束。另限活跃上传/下载、控制请求、块内存、带宽、预留字节及元数据/块数量。
慢传输、连续空帧采用专门空闲/总期限，不复用文本接口的两秒正文期限。

Linux 存储使用相对目录描述符和私有权限，拒绝软/硬链接、特殊文件、路径穿越、根目录
替换和既有目标。不可变分块存储避免强制再拼出第二份完整文件；先不做跨所有者去重，以免
泄露可见性或配额信息。显式保留/回收不能由查询失败推断数据不存在，进而删除已发布、
已授权、正在读取或结果未知的数据。

## 交付顺序和验收

| 阶段 | 进入下一阶段前的证据 |
|---|---|
| 传输契约与流式核心 | 大于旧 Artifact 上限的真实文件、有界缓冲、准确长度/摘要、块边界/溢出/来源变化拒绝、私有临时文件安全 |
| 持久上传与发布 | 确认分块、配额竞争、断线/重启核对、重复/冲突块、文件/元数据故障和未知提交处理 |
| 发布与接收权限 | 跨人/跨实例拒绝、账号重建、真实等待中的到期/撤权、准确版本授权、不放宽旧私人读取 |
| 集中适配与客户端 | 认证分块往返、响应/工作容量、可续传中断、安全保存与进度，随后显式 UI/SDK/部署接线 |
| 桌面互传 | 显式配对、节点认证、版本协商、接收者绑定委托，以及同一恶意分块/取消测试 |

覆盖真实磁盘满/短写、损坏/缺块、请求丢弃、重启检查、清理守卫及故障后的健康正控。
基准测量代表性大文件和多接收者下的吞吐、峰值内存、工作占用与磁盘放大。进程内或模拟
传输测试不等于浏览器持久保存、真实 TLS/局域网性能、部署验收或桌面互通。

[贡献流程](../../CONTRIBUTING.md)要求实施前创建提案 issue。清单/流式与私有暂存步骤不修改运行
监听或存储 Schema。上传意图后续增加独立全新 Schema，但不安装到在线数据；这些组件及独立分块日志均不改变
Artifact/文本限额、公共 API、发行版本、部署数据或成熟度证据。整文件字节核验仍只读；独立不可变发布元数据不是当前认证、永久物理封存或下载授权；回执丢失/重启协调及物理空间准入仍未完成；
持久化、授权、传输和客户端验收完成前，不宣称集中分发已经接通。
