# ADR-022 会话授权的任务输入换版

状态：**C2-J 已收录于源码版本 0.4.9**。决策日期：**2026-10-03**。

所有者发布新的不可变内容后，可以显式替换 Draft 任务保存的有序 Artifact 引用。这一切片连接任务
payload 编辑所需的后端准备层，不代表浏览器草稿已接入服务端，也不新增公共 HTTP 命令。
本切片首次收录于源码版本 0.4.9；后续内容 HTTP 准备层保持独立。

## 命令契约

`replace_session_input_task_inputs` 接受当前 Session、可信 `SessionTaskInputsWorkspace`、
Task ID、预期任务修订号，以及 1–32 个准确 Artifact 引用；目标必须是已有输入的手工任务。
`replace_session_catalog_task_inputs` 使用 `SessionCatalogTaskWorkspace`，允许 0–32 个引用，
包括空与非空输入之间切换；写入前后都将完整存储定义与配置中的准确条目比较，不调用提供器。
原先无引用的手工任务入口不会因此获得换版旁路。

两个命令都从当前身份与成员关系推导所有者；教师角色不授予访问其他成员私人任务的权限。
仅 Draft 能换版，拒绝过时修订、完全相同的有序列表、重复 Artifact/修订坐标、超限列表和错误作用域。
调整不同引用的顺序算作修改。标题、定义、所有者、创建时间及状态不变；成功换版只将任务修订加一并
更新时间戳。

新列表是准确的 Workspace、Artifact ID、修订 ID 和摘要，不是正文、文件名、本地编辑器 ID 或
“使用最新版”的请求。发布新 Artifact 是另一次授权操作；任务换版失败不会删除、接管或回滚该内容，
也不授权自动重试。旧 Artifact 版本与 Review 判断保持不变。

## 授权与事务

换版复用[任务输入事务](session-task-inputs.md)：先锁来源与注册表，再锁任务元数据及任务行，随后
把全部旧、新引用按同一全局 Artifact 顺序检查，总数最多 64 个。即使某个旧引用将在换版后移除，也
必须验证。坐标相同但摘要不同的引用不能去重，否则合法旧内容可能掩盖伪造的新引用。修改操作逐项
释放已验证内容，不向调用方返回全部字节。

任务更新与 `cyanrex.task.inputs_replaced` outbox 事件在同一事务写入。写后复查旧、新内容并读回
待提交任务；共享授权检查再用新鲜数据库时间复核所有原始命名空间身份、当前账户世代、经审计的
活跃成员关系和准确 Session。确认提交后才返回结果；使用同一预期修订的并发保存不能全部成功。

仍使用 10 秒命令时限及原有语句/锁等待时限。提交附近的取消、超时或响应丢失不证明回滚，本轮没有
命令回执或结果对账。内容检查无法阻止同 UID 在检查后修改文件，也不保证任意延迟提交期间会话仍有效。

## 存储兼容性

Task 存储 Schema 现为 **2**，仅允许在专用空命名空间显式安装。读取和写入均拒绝 Schema 1，
不自动升级、接管或修复；没有触碰已有部署或教学数据库。共享 `CoreSchemaVersion` 仍为 1。

新 Schema 接受独立换版事件和修订大于 1 的 Draft 快照。创建仍要求 Draft 修订 1，后续 Draft
链头必须对应 `cyanrex.task.inputs_replaced`，其他状态对应 `cyanrex.task.status_changed`；
状态图没有返回 Draft 的转换。这些检查只证明当前任务与事件链头一致，不证明完整历史或写入来源。
存储层换版方法仅限 crate 内部，不新增让外部调用者自行指定所有者的公开入口。

## 验证与下一边界

单元测试覆盖不可变字段、修订溢出、有序无变化、引用上限与事件选择。显式的一次性 PostgreSQL
用例覆盖真实 Artifact 修订、目录任务空输入、旧/新内容检查、私人所有权、Schema 兼容、身份生命周期、
并发写入、触发器故障、延迟提交失败、过期/退出及取消。CI runner 先核对准确用例名称再执行，实际
验收结果见[项目状态](project-status.md)。

未发布的 [C2-K 内容清单](task-content-manifest.md)只新增元数据/快照纯契约，不改变本存储或命令。
独立 [C2-L 可信存储](task-content-store.md)已在 Schema 3 支持元数据原子编辑，本 Schema 2 Session
适配器会拒绝该格式。[C2-M](session-task-content.md)另行提供专用 Session 内容/字节组合；公共认证/CSRF、
浏览器保存及冲突界面、二进制附件、数据迁移与在线切换仍是后续工作。本轮不执行代码、不验证类型化领域证据、不签发规则 Review、不扩大跨用户
权限，也不验收 Task。
