## 显式组合

`FileUploadPublicationStore::new` 固定受信任 PostgreSQL 配置。
`install_empty_namespace` 仅显式安装独立的全新命名空间；构造、准备和正常应用启动都不安装或
迁移。原上传与分块日志 Schema 不变，`0020_collaboration_file_publications.sql` 不是自动迁移。

`FileUploadPublisher::new(local, journal, publications)` 要求相同工作区和三个不同命名空间，
复用本地适配器控制准入与原暂存工作预算。`prepare(upload_id, owner, account_id)` 固定原来源
预留、完整已确认日志目标及发布 Schema 身份，不读文件、不写发布记录。受信任调用方提供的
所有者不是当前 Session 认证或权限。

`FileUploadPublicationAttempt` 是不透明的一次性尝试，仅原发行者或其克隆接受。
它不能克隆、序列化、恢复，也不能从元数据读取构造。控制容量拒绝保持 Ready；准入后在第一次
await 之前进入 Unknown，只有最终核对通过并返回原尝试回执时才进入 Confirmed。

## 必需字节与原身份

日志读取选择完整目标上传，不用所有者/账号过滤掩盖外来行。它核对有界索引顺序、条数、分块
几何、准确所有者/账号代次、来源/根绑定、清单摘要、Confirmed 状态与原行 nonce。
有效缺块或 Unknown 返回 NotReady；损坏、多余或混合绑定行拒绝。空文件也要求健康的原日志
身份与零目标分块行。日志状态始终不是字节证明。

发布器先复核原来源与日志，再按序读真实私有 `u1` 分块，核对每块及整文件摘要；请求发布插入
之前再次检查原来源、日志及文件快照。提交确认之后，继续核对原来源、日志、发布行/Schema
和同一个原文件观察，不能用新路径或匹配元数据替代原观察。最后文件检查与返回回执之间没有
await。

文件工作复用 **64 KiB** 字节缓冲与常量数量的打开分块描述符；最多保留 **16,384** 个有界
名称和快照。发布步骤不增加组装文件、复制、写入、chmod、fsync、重命名、删除或自动清理。
原 `u1` 命名仍逐块散列完整清单，平方级命名工作不是吞吐量承诺。即使等待者取消，实际排队
或运行任务也持有原工作许可直到结束。

原固定身份复核使用新鲜 READ COMMITTED、READ ONLY 事务；没有 SQL 锁跨越文件工作。
独立存储和文件观察不是原子快照。同 UID/root 与数据库管理员仍受信任；这些检查不是 WORM
封存或断电测试。来源/根/日志指纹不标识整个数据库集群，也不认证对端。

## 仅首次创建的发布存储

每条发布记录保存一次完整规范有界清单、准确所有者/账号代次、内部来源/根/日志指纹及唯一
UUIDv4 nonce。公开 `FileUploadPublicationRecord` 仅提供上传、所有者、账号与清单元数据，
不提供内部绑定键/指纹或可执行提交确认。

一个固定命名空间的受信任容量为 **1–256** 条，包含空文件和全部所有者/账号代次。
上传 ID 与 `(file_id, version_id)` 都在该空间永久唯一；改变所有者、来源或根不能收编已有
坐标。Conflict 在容量之前检查。原逻辑上传预留继续占用，发布不重复计算字节额度，也不预留
物理磁盘。

写事务使用 READ COMMITTED 和固定表/marker 锁，校验完整有界账本，只插入一行，执行延迟
约束，再核对准确预期账本与原 Schema，最后请求同步提交。先读取最多 257 个标量头，再逐条
解码一个有界清单，不累计 256 份完整清单。`FileUploadPublicationStoreError` 区分配置、
Schema、记录拒绝、Conflict、CapacityExhausted 与 StorageUnavailable；不禁用配置的只读策略。

没有持久发布 Unknown 行或之后的确认更新。每条存储行都是不可变的已发布协议元数据。
`get(upload_id, owner, account_id)` 是受信任的准确只读快照，不是完整账本审计、当前文件健康
检查、原字节历史回执、恢复尝试、重试权限或接收授权。

## 失败与取消

| 情况 | 存储的发布记录 | 原尝试 |
|---|---|---|
| 控制准入未通过 | 不变 | Ready |
| 准入后在插入之前失败或取消 | 可能不存在；不确定结果不是回滚证明 | Unknown |
| 提交成功，但确认或最后检查失败 | 可能已有不可变已发布行 | Unknown |
| 插入确认且全部最后原身份检查成功 | 已发布元数据 | Confirmed 并返回不透明回执 |

`FileUploadPublicationError` 区分 NotVisible、NotReady、容量、来源/日志/发布错误、字节不可用
与 Unconfirmed。它不靠查询匹配元数据提升不确定尝试。全新准备是新的核验，不是重试或恢复
旧尝试；未发生插入时，没有持久占用发布坐标。已有发布行永远不收编或覆盖，原预留、日志和
文件都保留。
