## 主动保留的边界

- 特权 Engine 面向可信自部署教学环境，不面向公网多租户。
- 本地执行共享同一个 Linux 内核；配额是资源控制，不等于学生隔离。
- Engine 仍是单进程。Agent 注册、远程作业、挂载和模块生命周期尚无多副本协调模型。
- Aya 当前覆盖已支持的 tracepoint 路径，bpftool 仍是兼容性最广的路径。
- 远程 Agent 只编译和诊断，`/ebpf/run` 仍在本地执行。
