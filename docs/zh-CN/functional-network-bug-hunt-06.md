## 保留的行为与权威边界

- 协议仍为按用户发送的原始 Event JSON，没有新增 ID、游标、字段、路由或角色。会话/Origin 检查
  仍先于按用户订阅，查询参数不能选择他人。共享内核中的追踪标记和声明行集合不构成来源认证。
- 匹配记录仍采用 200 条恢复缓存、50 次命中展示上限，按出现次数处理快照重叠。初次/重连快照可能
  落后于实时持久化；恢复不是原子衔接或恰好一次。重连成功不会擦除缺口提示。
- 异常 JSON、不符合 Event 结构和非文本帧提示可能缺失，但不单独触发重连。被正常筛选排除的
  有效事件不算缺口。握手/快照各 10 秒、随机退避、HTTP 401/403 和关闭码 1008 停止重试均保留。
- 编辑让观察结果失效，不卸载程序。F9/侧栏/清空只修改下次显式运行的请求断点，不移除正在运行的
  探针；当前有效命中可持续高亮，直到该运行上下文失效。高亮前检查文档行范围，但不新增编辑时
  自动跟随代码移动断点行号的能力。
