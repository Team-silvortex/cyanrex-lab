# ADR-017 会话授权的私人手工任务

状态：**C2-E 已收录于源码版本 0.4.8**。决定日期：**2026-10-03**。

本轮把持久 Session、C1 身份与成员关系、C2 Task 操作放进同一个数据库事务。活跃成员可以创建、
读取和推进自己的纯手工任务，所有者由服务器解析，调用方不能自报。这是内部授权准备层，不是
公共任务工作流；源码版本 0.4.8 没有切换现有教学认证、路由、部署或真实数据。

## 权限与任务范围

`DurableAuthSource` 新增三个入口，均要求当前 Session 和受信任的 `SessionTaskWorkspace` 配置。

| 入口 | 行为 |
|---|---|
| `create_session_manual_task` | 接收任务 ID 与标题，创建无领域定义、无 Artifact 输入的私人 Draft |
| `get_session_manual_task` | 只返回当前所有者的任务；不存在或属于别人时返回空 |
| `transition_session_manual_task` | 核对所有者和预期修订，再执行已有的手工状态转换 |

准入要求准确的来源账号代次、未退役且活跃的 Human、活跃 Workspace 和经审计的活跃成员关系。
此私人工作策略不要求教师角色或部署 Grant，也不自动分配它们；空角色列表的有效成员可以使用。
教师或部署管理者不会因此得到他人私有任务的访问权。未绑定、无成员关系、停用、退役、退出、过期
或审计头不一致均拒绝。同名重建账号不能继承原 Principal 的任务。

这三个 C2-E 命令对带目录定义或 Artifact 输入的 Task 仍返回 `UnsupportedTask`，即使它属于调用者。
[C2-G](session-task-inputs.md)另增同事务、无定义的私人准确输入适配器；
[C2-I](session-catalog-tasks.md)独立准入服务端配置的完整目录定义及 0–32 个输入，不执行提供器。
两者都不扩大这些纯手工方法。没有列表、转交、共享、人工验收或自动完成入口；规则通过和 Run
成功仍不能批准 Task。

## 数据库边界与事务

源账号、Session 与 C1 注册表处于同一个明确的私有命名空间；Task 使用同一数据库内另一明确命名
空间。两者共用来源连接及一个提交，不是两个连接池各自提交。`SessionTaskWorkspace` 只接受规范的
非 public、非系统 Schema 名称和 Workspace，字段私有且不可反序列化。它必须来自服务端配置，不能
直接取自请求；这些类型约束本身不是认证。普通命令不安装、升级、修复或认领命名空间。

命令先核对来源命名空间名称/OID、唯一有效搜索路径及没有临时命名空间，再用关系锁核对 14 张来源/
注册表的归属、永久普通表性质、主键和认证源结构，拒绝 RLS、分区、继承与临时遮蔽。之后按来源
元数据、注册表元数据、authority、身份/策略及 Task 元数据/任务行的顺序加锁。authority 写锁会使
同一 authority 下的这些命令串行；这不是已经优化的并发性能承诺。

TaskStore 的 crate 内部组合方法只借用事务，返回待提交结果，不能另开连接或自行提交。外层事务
完成当前 Session 解析、审计身份/成员核对、Task 写入与 outbox，写后验证目标名称/OID 未改变，
恢复来源搜索路径并重新核对来源、身份、成员，最后用数据库的新鲜时间复核准确 Session。只有提交
得到确认才返回成功。搜索路径切换使用事务局部设置，正常提交、失败或取消后连接不能遗留 Task 路径。

受保护读取也在这条加锁路径中完成；不是维护工具的可重复读观察，更不是后续命令的授权凭据。
退出或撤权等待已准入的命令提交，先完成的退出则阻止后来的命令。等待期间过期的 Session 不得写入。
最终复核不等于在任意延迟的 COMMIT 期间持续有效，也不会撤回已经提交的工作。

## 失败语义与保留限制

Task 和事件保持原有原子提交、版本冲突与终态限制。写入抑制、延迟提交失败、写后身份/成员/来源
变化及搜索路径替换均不得发布成功。整体时限 10 秒、语句 5 秒、锁等待 2 秒；错误经脱敏，不暴露
SQL、令牌、摘要或数据库路径，也不降级成内存成功。

取消、超时或丢失提交确认仍不证明回滚。本轮没有命令回执、成功重放、恢复或安全自动重试机制。
数据库检查不是完整 Schema 指纹、完整历史对账或对数据库特权操作者的防护。

原来的可信 `TaskStore` 接口仍可直接使用，尚未设置阻止旧写入的切换栅栏；outbox 没有新增来源标记，
因此不能反推全部历史 Task 都经过此授权入口。ArtifactStore 与 ReviewStore 的直接接口仍接受可信
归属；[C2-F](session-artifact-commands.md)另增 Session Artifact 适配器，不授予 Review 权限。
没有新增数据库迁移模板、环境开关、HTTP/CSRF 接入、UI、启动钩子或初始化 CLI。

## 验证与下一步

原 C2-E 测试包含 3 条默认用例，验证命名空间输入、失败不降级和禁止分离式认证/在线组合；
17 条显式 PostgreSQL 用例
覆盖私人所有权、无需教学/部署角色、未绑定/撤销、领域任务拒绝、修订竞争、终态、退役及同名重建、
目标命名空间、审计缺失、停用/归档、事件/提交故障、写后权限变化、RLS/临时遮蔽、合法克隆命名空间
替换、退出/过期/撤权顺序、取消与连接池搜索路径恢复。

`scripts/test-session-task-storage.sh` 要求一次性数据库，检查每个准确名称存在后才运行；CI 调用
同一清单，脚本回归检查完整性。故障用例只可用于合成测试数据，不能指向已部署数据库。执行结果及
没有重跑的检查见[项目状态](project-status.md)。

[C2-F](session-artifact-commands.md)已补当前 Session 的私人 Artifact 访问；[C2-G](session-task-inputs.md)继续在同一来源事务组合私人准确输入与 Task 命令。[C2-H](session-review-commands.md)增加带准确所属证据的私人人工 Review 命令；领域策略、
历史写入来源与 Task 验收仍待完成。跨用户协作必须有独立资源授权，
不能从教师或部署 Grant 推导。公共入口、旧数据离线映射、
可信旧写入栅栏、内容保留及可靠 Run/事件交付仍待完成；C2 与 C-M2/C-M5 尚未整体验收。
