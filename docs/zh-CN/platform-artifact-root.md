# 平台 Artifact 私有目录预检

于 **2026-10-15** 收录至 **0.6.0** 源码，见[发布验证](../../reports/releases/0.6.0/README.md)。
下列日期说明保留原实施范围，不是新的部署验收。

这是 2026-10-15 的 0.5.9 之后未发布跟进，在[平台宿主提案 3](https://github.com/Team-silvortex/cyanrex-lab/issues/3)
下增加独立只读目录门槛。它检查明确选出的既有 Artifact 根，不构造存储、不连接数据库，也不
启动宿主；与[数据库目录预检](platform-host-preflight.md)分开。

## 既有私有目录

`inspect_platform_artifact_root(config, root)` 是可信组合方调用的同步准备接口，复用 Artifact
存储已有的描述符相对遍历，不新增另一套路径策略。路径必须绝对、有界并经过受保护祖先链；
逐段打开时不跟随符号链接，缺失路径、父级穿越或非目录组件均拒绝。

最终目录必须由当前有效用户拥有，模式精确为 `0700`，不能附带特殊权限位。祖先必须由 root
或当前用户拥有，且不可由组或其他用户写入；root 所有的 sticky 目录例外，例如常见临时目录。
用户保存目标允许的 `0750`／`0755` 不适用于这个私有存储根。

检查不创建目录、不改权限、不枚举条目、不读取 Artifact 字节，也不检查可用空间或修复权限。
它不证明内容完整；非空目录也能通过，里面的内容不在此门槛的检查范围。

## 原目录绑定

`PlatformArtifactRootObservation` 保留原目录描述符、完整宿主配置、准确路径拼写，以及 device、
inode、UID、GID 和完整模式快照。它没有 Debug、Clone、序列化或公开描述符访问器。返回观察
之前会再核对可见路径与所持描述符；失败只返回 `ArtifactRootUnavailable`，不返回原始文件系统
错误或所选路径。

`verify_platform_artifact_root(config, root, expected)` 将原描述符及新遍历得到的可见目录与原
快照比较。配置或路径拼写变化、目录替换、祖先不安全或目录安全元数据漂移，均返回
`ArtifactRootChanged`，不接纳新目录。观察对象的 `matches` 只被动比较记录字段，不做实时检查。

目录时间戳和链接数不作为身份字段，因此普通内容增删不会误判为根替换。原目录和权限恢复后，
后续核对也可以再次匹配；这不是每一次中间变化的历史证明。

## 调度与交接边界

这些是同步元数据操作，没有文件系统 I/O 的硬性期限。可信调用者自行决定在哪个线程运行；
接口不暗中创建 worker、请求任务或取消预算。缓慢或不可用的文件系统可能阻塞调用者。

观察固定最终根，不固定每个祖先的原 inode。检查成功只表示某一时点匹配，不隔离同 UID／root，
不证明 mount namespace、进程能力或持续权限，也不会让进程自动变为低权限。

所持描述符不会作为新的运行能力交给 `ArtifactStore`。之后独立按路径打开存储仍有时间间隙，
必须保留存储自身的原目录防护。不挂载服务、不签发 Session、不安装或迁移存储；暂存根仍需
另行检查。

## 验证

默认 Unix Rust 回归只使用私有合成目录，覆盖只读成功、非法和特殊文件路径、符号链接、目录／
祖先权限、完整配置与准确路径绑定、替换与恢复，以及正常内容增删。不需要数据库夹具或特权
所有者变更；默认后端门禁与 CI 会正常发现这些测试。

只运行这条边界：

```bash
cargo test --manifest-path engine/Cargo.toml --locked --test platform_artifact_root_tdd
```

这些验证不证明存储 schema 兼容、权限历史有效、Artifact 字节健康、部署可写或 Linux 进程隔离
已经成立。
