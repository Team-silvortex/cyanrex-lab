## 可信选择及原对象绑定

`FileSaveTarget::open(parent, leaf)` 只经既有受保护祖先、描述符相对 no-follow 策略打开
已有、本 UID 私有的 **0700** 目录；不创建／改权限、不预留名字、不打开输出。
UTF-8 basename 为 **1–255 字节**，不能空、`.`、`..`，不能含斜杠、反斜杠、NUL 或控制字符。
宿主独立提供名字，`manifest.display_name()` 从不成为默认目标。旧私有构造仍拒普通 0755。
独立[本人目录选择](large-file-user-save.md)以显式 `open_user_directory` 支持本人 0700／0750／
0755，不放宽私有暂存政策，也不允许共享可写目录。

目标克隆共享原父目录描述符、路径及身份，无公开字段、序列化、路径／描述符 getter。
选择的父目录须不同于暂存根；该对象是本地可信宿主能力，不是远端请求或工作区权限。

`ChunkStaging::save_assembled_file(&manifest, &assembled, &target)` 借用原 `AssembledFile`，
返回只公开 `file() -> &FileVersionRef` 元数据的 move-only `SavedFile`。两种确认都无公开
构造、Clone、序列化、字节／路径 getter 或可写描述符；旧下载／拼装方法和错误变体保持兼容。

拼装现仅在真实最终核验成功后，内部保留**原只读 `f1` 描述符**、原 Snapshot、完整强类型
清单指纹、原根身份／描述符，不从旧版本元数据重开名字补造证明。写者保持存活至原只读
inode 已打开并核对，再在实际读回前关闭。相同替换字节、同版本坐标或另一根均不能替代
原对象；此跟进延长私有生命周期，不增加远端权威。

Scope、完整版本、完整清单指纹及缓存原根绑定在工作准入前核对；指纹为有界同步元数据
工作，不是载荷 IO。新入口不将已有 `f1` 采用为回执；同字节不同 inode 替换、unlink、
hardlink、权限／长度／内容漂移或根替换都关闭式拒绝。

## 校验复制与独占输出

已准入任务复核两原根、保留的原源文件／根描述符及可见原 `f1` 快照。这些检查通过后，
已有目标均 Conflict，包括空／有效文件、目录、FIFO、hardlink 和悬空 symlink，从不打开写入。
在创建前实际核验原源有序块／整文件 SHA-256 及准确 EOF；再次复核根和源后，才以
`O_EXCL | O_NOFOLLOW`、请求 **0600** 权限独占创建。

第二遍源读取经既有 **64 KiB** 流核心校验复制。读取共用原 FD，但每次调用有自己的位置
读取（`pread`）游标；同一借用确认并发显式保存不会混用游标。再次检查原源，输出变为 **0400**，
同步文件和父目录，在写者仍存活时打开／核对原只读输出 inode，随后关闭写者。
第三遍实际读取输出，核验每块、整文件摘要和 EOF；确认前核对原源／输出描述符、可见名、
快照及两原根。

成功只表示此次所选新文件实际同步／读回及当时观察到的原路径绑定，不是原子公共发布、
断电验收、抗同 UID／root 变更的永久封存、可执行安装或持续远端授权。远端授权到期不会
抹掉此前已披露的本地字节；本可信本地操作不请求 GET。

## 准入及不确定结果

保存与 stage／verify／assembly 共用原 **1–16** 暂存 workers；fail-fast 准入先于元数据
克隆及一次 blocking 派发。实际排队／运行任务跨等待者或确认对象取消保有 worker、原证明
及目标父目录。取消等待者不返回 ACK，也不停止已排队／运行的文件任务，原任务仍可能完成；
不增加新编排续跑、网络请求、重试、恢复或采用，不提供磁盘／CPU 硬期限，
也不单独保有整个下载流程 lease。

`FileSaveError` 为静态 `InvalidInput`、`CapacityExhausted`、`Conflict`、`Unavailable`、
`Unconfirmed`。源／根检查可在目标存在性检查前先返回 `Unavailable`，存在性检查又先于
完整源载荷预校验；创建前失败不创建或改动目标。此前检查通过时，已有目标为 `Conflict`。
其他创建错误、创建后失败及工作结果丢失保守为 `Unconfirmed`，保留部分或完整不确定文件
（初始请求 0600、最终 0400）。原绑定有效时，重复显式保存同一目标不改其内容，只冲突；
存活原证明可另向明确选择的新目标
复制，不依据匹配保留文件授权恢复或覆盖。

每个存活拼装确认保有两个私有描述符，随最后内部证明引用释放，不持暂存 worker。目标
保有父目录描述符，任务使用常数描述符集合及有界清单；保留确认／独立暂存句柄无全局
描述符／RSS 配额。**16,384 块／64 GiB** 声明限额和三遍载荷是结构边界，不是实测吞吐或
物理磁盘预留；源块和私有 `f1` 不删除，选定保存会另增加一份完整磁盘副本。

## 验证及剩余连接

新增[授权交付调用](large-file-delivery-client.md)可将准确清单、有序块、原拼装和本所选保存
放入同一实际任务持有的整流程名额中；独立保存仍是无 GET／父下载 lease 的本地原语，
界面和续传保持独立。

`file_save_tdd` 核验真实私有文件、原对象拒绝、选定名字独占及独立 EOF／SHA／模式／inode／
权限。私有工作／阶段测试覆盖实际排队／运行所有权和确定性源／输出／根漂移。
`fileSave` 守卫只检查组合／库存，不证明实际保存。既有显式清单客户端 SQL 桥接另将授权
网络下载接到所选本地输出；原生执行结果另录于下文。

入口仍是可信宿主内部准备层，不挂载。界面确认／文件选择、共享可写目录策略、公开 Session
签发、SDK／OpenAPI、续传／进度／重启、点对点、迁移和局域网部署仍独立。
版本／依赖、已发布 0.5.7 验证、**106 段历史状态**、**42 份既有执行尾部**及分日期张量不变。
