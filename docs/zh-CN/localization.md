# 界面与文档翻译

源码 **0.5.9** 已收录，原为 **0.5.8** 之后的跟进，核对日期 **2026-10-13**。英文、简体中文、西班牙语、日语和韩语
现在各明确包含 **865 条界面文案**，插值参数一致。这是词典完整率，不表示所有外部诊断或
第三方菜单都已翻译。

## 界面行为

本地 payload 编辑器翻译纯文本选项、读屏输入标签和全部 **22 条基础片段说明**。切换界面语言
读取最新文案，不替换模型、不改变插入代码、payload 修订或撤销历史。语言 ID 和 API 名称不变。

eBPF 编辑器翻译本地悬浮／补全说明和修复标题，本地诊断展示复用同一适配器。修复先读取稳定的
本地诊断标识，再使用原来未标记英文消息的兼容路径；译文不决定修复操作。插入代码及 clang
语义详情保持原样。

已知教学摘要、自动反馈、环境说明和常见认证错误在展示时翻译。适配器只匹配完整的已知旧模板，
参数有界；未知消息逐字保留。不改变后端记录，不把展示文本当作权限、评估或执行成功依据。
教师评论与提交源码不进入此翻译适配器。

编译／加载 stdout、stderr、操作系统／工具原始输出、协议字段、标识符和代码示例保持原样。
本轮没有为 Monaco 第三方内置菜单或外部语言服务诊断增加全局 NLS 配置；它们与项目自身的
界面词典属于不同范围。

## 文档来源

韩语（`ko`，한국어）可在登录页和侧栏选择，偏好保存在当前浏览器。页面语言随选择更新；
回退到英文的文章单独标记 `lang="en"`。暂未提供韩语课程正文；缺失时先尝试英文，英文
不可用才尝试简体中文，并以韩语提示实际正文语言。界面完整率不表示课程、教师原创内容
或第三方菜单的翻译完整率。

`docs/en` 下每个 Markdown 主题现在都有 `docs/zh-CN` 对应，包含完整的
[架构提案](next-architecture.md)。原日期、版本、固定证据和提案状态保留；翻译不刷新架构
或发布验收。说明性图中文字已翻译，但图连接和状态序列不变。

双语树之外的 16 份公开指南增加相邻中文版：根 README、贡献、安全、行为准则和 TDD 政策，
前端／Engine、SDK 使用／稳定性、Docker 使用／离线部署、脚本清单，以及模块索引和三个模块
指南。英文入口链接中文对应。可执行示例与命令逐字保留。

`docs/` 是权威来源，`frontend/public/course/` 由 `node frontend/scripts/sync-course-docs.mjs`
生成；编辑来源后同步。`--check` 逐字节检查一致性，不修改来源或副本。同步不等于译文质量
验证。本轮不逐条翻译或改写历史更新日志和归档执行报告。
