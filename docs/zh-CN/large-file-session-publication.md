## 可信配置与不透明输入

`DurableAuthSource::file_publishing_workspace(publisher, grants)` 固定
`SessionFilePublishingWorkspace`。既有 `FileUploadPublisher` 和
`SessionFilePublisherGrantWorkspace` 必须使用准确相同的工作区／权威和四个不同非系统命名空间。
构造不连接、不读取文件、不安装、不迁移、不转换角色。宿主独立于请求配置发布器、私有根及授权账本。

`publish_session_file_upload(token, workspace, grant_id, attempt)` 接收由可信发布器的纯元数据
`prepare` 方法产生的既有不透明 `FileUploadPublicationAttempt`。准备仍使用可信来源归属，并不
自身认证 Session。命令从当前审计的活跃 Human 成员关系推导操作者，要求与 attempt 的所有者
及准确账号代际一致。客户端所有者声明、教师／部署角色、管理配置不能替代活跃发布授权。
旧可信发布器仍可由可信代码独立调用；本适配不会暗中改变该 API 的权限要求。

## 权限与发布顺序

1. 廉价 token／认证源检查先于发布器／控制准入。错误发布器、非 Ready 输入或控制额度耗尽
   均不改变输入状态；原本符合准入条件的 Ready 输入在准入失败时仍为 Ready。准入在第一次
   await 前设 Unknown，既有共享控制槽保留至认证、文件工作及最终复核结束。
2. 一个 READ COMMITTED 认证源事务校验准确当前操作者及本人选中授权，包括完整原历史、
   活跃状态和新鲜数据库时钟有效期。原认证源／Registry／授权身份和准确 Session 留在不透明
   内存中；此提交只确认准入元数据，不提交发布或产生可脱离事务复用的权限。
3. 释放连接及全部 SQL 屏障后，既有工作器检查完整已确认日志和真实有序分块／整文件字节。
   相同原文件观察保留供最终检查；文件工作期间没有认证源 SQL 事务。
4. 新认证源事务复核第一次认证源／Registry 身份及准确原 Session，重取原授权三表 SHARE
   屏障；历史改变或安装被替换即拒绝，不重新采纳。原上传／日志另取 SHARE 屏障，只创建
   发布写入使用原安装及完整有界预期账本。
5. 调用者恢复 `synchronous_commit = 'on'`，刷新 `SET CONSTRAINTS ALL IMMEDIATE`，复核发布／
   上传／日志／授权及原固定。最终当前操作者／Session 检查后，一个新鲜时钟样本同时覆盖
   授权有效期和 Session 过期；之后不再执行 SQL 即请求 COMMIT，不覆盖配置的 READ ONLY 策略。
6. 只有该认证源 COMMIT 确认才能产生私有发布确认。随后仍独立检查原上传／日志／发布和
   相同原文件观察；全部成功才返回回执并设 Confirmed。仅存储 Published 行不能恢复确认。

首次授权时间采样是准入观察，不是字节 IO 全程许可；在后续准入检查或文件工作期间过期，最终
发布仍必须拒绝。早期元数据不作为权限布尔值复用。协作撤权写入与最终授权屏障排序，所有前序
SQL 等待结束后，以最终同一个新鲜时钟样本检查有效期，不使用事务开始时间。这是最后提交前观察时的权限，不是确认到达或已派发文件工作的每个
瞬间仍有效。取消不会杀死排队／运行工作；工作槽仍由工作本身持有。
每个认证源 SQL 阶段各有十秒外层上限；这不是整个文件流程的截止时间，也不保证取消后文件工作已停止。

借用事务的上传／日志／发布检查只接受同一原受限命名空间的准确裸名或规范引号写法，仍要求
原 OID、关系、形状及安装相同。额外原始搜索路径项即使不存在也拒绝；旧可信直接 API 和提交后
确认复核继续保留原始搜索路径的严格身份检查。

## 失败边界

`SessionFilePublishingError` 区分 Session、Grant、Publisher、InvalidNamespace 和 PermissionDenied。
缺失／外人／非活跃／时间不符合的授权不允许字节工作；原历史改变也可能返回明确完整性错误。
准入后错误或取消均保留 Unknown，不自动重试、恢复、采纳、清理或从匹配元数据转换回执。

插入与权限及最终操作者检查共享认证源事务。明确提交前拒绝可以回滚该事务，但超时或丢失确认
不证明回滚。已确认行可在后续文件／元数据复核失败后保留。授权不会删除或一次性花费，可在
有效期／撤权前授权其他符合条件的上传；永久上传／版本唯一性及保留的上传／发布额度不变。

原观察检测元数据／对象漂移，不提供 WORM 封存或同 UID／root／数据库管理员隔离。发布只校验
字节，不合并、复制、重命名、解压、执行或交付；既有 64 KiB 缓冲、有界清单及工作生命周期额度
保持不变，不增加物理磁盘预留、吞吐／RSS 或掉电保证。
